Planner guard — the model sits under the rules

The model may argue about the order; it cannot widen the plan. Every proposal goes through a structural gate, and the gate's verdict — accepted or refused — is written to the evidence ledger.

Legal basis and data minimisation

  • No breach, no authority to query — the system cannot turn into productivity surveillance (purpose limitation).
  • The default query returns a verdict, not coordinates: "is this worker inside the zone?" (Location Verification).
  • Coordinates only in a probable collapse case, once; only a coarse summary is written to the ledger.
  • The SIM cards are employer-issued; queries run under the operator's consent framework for employer-issued lines.
  • The ledger is itself a per-worker presence record — bounded and counted. Coordinates enter it only after an escalation, once, coarsened to 3 decimals (coordinates stored: —).
