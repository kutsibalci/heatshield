Legal basis and data minimisation

  • No breach, no authority to query — the system cannot turn into productivity surveillance (purpose limitation).
  • The default query returns a verdict, not coordinates: "is he inside the zone?" (Location Verification).
  • Coordinates only in a probable collapse case, once; only a coarse summary is written to the ledger.
  • The lines are issued by the employer; permission is obtained within the operator's consent framework.
  • Continuous location history is never retained (location_history_size: 0).
